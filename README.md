# Simple Calculator

A small command-line calculator written in Python, used to practise Git and GitHub workflows
(branching, committing, merging and resolving merge conflicts).

## Features

- Addition, subtraction, multiplication and division
- Division by zero raises a clear error message
- Division results are rounded to 2 decimal places

## Usage

```bash
python calculator.py 10 / 4
```

## Running tests

```bash
python -m unittest -v
```
